# Proyecto de Autenticación de Usuarios con Firebase

Este es un proyecto de autenticación de usuarios utilizando Firebase. La aplicación permite a los usuarios registrarse, iniciar sesión y gestionar sus permisos a través de Firebase Authentication.

## Funcionalidades

- **Registro de usuarios**: Los usuarios pueden registrarse utilizando su correo electrónico y una contraseña segura.
- **Inicio de sesión**: Los usuarios pueden iniciar sesión con su correo electrónico y contraseña.
- **Autenticación de permisos**: Dependiendo del rol o permisos del usuario, la aplicación puede permitir acceso a ciertas funcionalidades o recursos.
- **Gestión de usuarios**: La aplicación puede autenticar y verificar los permisos de los usuarios para acceder a áreas específicas.
